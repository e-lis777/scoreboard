# Легион: Android-админка

Требуются JDK 17, Android SDK 35 и Gradle 8.9. Сборка: `gradle :app:assembleDebug`.
APK: `app/build/outputs/apk/debug/app-debug.apk`.

Приложение открывает опубликованную админку, удерживает экран включённым,
подтверждает выход по кнопке «Назад», поддерживает импорт состава через системный выбор файла.
Название: «Легион · Табло». Векторная адаптивная иконка мяча.
Ссылка входа встроена в персональный APK: управление открывается автоматически.
Для повторного входа откройте шестерёнку → «Переподключить управление».
Не публикуйте APK: его обладатель получает доступ к управлению.
При сборке задайте admin.url в игнорируемом Git файле local.properties.

Закрытие приложения не останавливает запущенный эфирный оверлей. Пока оверлей
открыт, его запросы запускают синхронизацию Kimberly на сервере. Если закрыты
и админка, и оверлей, периодический опрос прекращается до следующего открытия.
При возвращении таймер рассчитывается по сохранённой точке старта.

Кнопка Home и принудительное закрытие Android не могут быть запрещены приложением.
Не требуется фоновая служба или разрешение на работу поверх других приложений.
